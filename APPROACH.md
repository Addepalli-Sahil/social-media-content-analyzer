Streamlit was chosen for rapid, user-friendly UI and easy deployment on Streamlit Community Cloud. PDFs are parsed with PyMuPDF page-by-page to preserve page markers and line structure; where PDFs lack extractable text (scanned documents) image OCR is used. Images are processed with Pillow and pytesseract to run Tesseract OCR. Analysis is deterministic: token counts, hashtag/mention detection, CTA keyword matching, a hook heuristic (first sentence conciseness and power words), and a simple readability proxy (average sentence and word lengths). These heuristics are combined with weighted rules into a 0–100 engagement score and concrete suggestions. Error handling includes file-type/size validation, graceful handling of empty extraction, and friendly user-facing messages. Loading spinners are shown during extraction and analysis. For deployment, requirements.txt and packages.txt declare Python and system dependencies for Streamlit Community Cloud. (Word count: 151)
